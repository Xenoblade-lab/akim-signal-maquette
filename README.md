# Maquette SIGNAL — Projet Akim

Maquette HTML interactive (style produit / Figma live) pour validation UX.

## Ouvrir

1. Double-clic sur `index.html`, **ou**
2. Via Laragon : `http://akim-outil-de-collecte-de-donnees.test/maquette/`  
   (selon le nom du virtual host), **ou**
3. Depuis le dossier :

```bash
start maquette/index.html
```

## Écrans

| Fichier | Contenu |
|---------|---------|
| `index.html` | Accueil / choix FO ou BO |
| `fo.html` | Front Office décideurs |
| `bo.html` | Back Office technique |

## FO inclus

- Vue d’ensemble (score, mentions, sentiment, alertes)
- Par plateforme (X, Facebook, TikTok)
- Thématiques & crispations
- Alertes
- Publications + export (maquette)
- Filtres période / plateforme / région

## BO inclus

- Sources de données
- Connecteurs & API
- Utilisateurs & rôles
- Monitoring
- Rétention / audit

## Design

- Typo : Syne + Outfit
- Ambiance : encre / teal / ambre
- Données : fictives (démo)
